# Clients

**Clients → list** shows every client on the platform. Search by name or phone, open a client to see their details, and export the list if you have the export permission. You can sort it by **Client** (name), **Centers**, **Reservations** or **Joined**; see [Lists](./getting-around#lists).

## How clients join

Clients sign in with their phone number and a one-time code, so there is no password to reset. A client who has not entered a first and last name yet is still **onboarding**.

## Generating a login code

If a client is not receiving the SMS, open the client and choose **Generate OTP**. You get a new 4-digit code to read to them. No SMS is sent, the code is shown only once, it expires after 5 minutes, and any earlier code stops working. This needs the **otps.create** permission.

## Per-center view

A center only sees its own clients: people who joined it, or who have a confirmed or completed purchase with it. Admins can open a center's client list from the center page.

## Blocking

A center can block a client. Blocked clients cannot book that center. Admins can see and add blocked clients from the center page.

## Deleted clients

Deleted clients are hidden everywhere but their history (purchases, reviews) is kept.
