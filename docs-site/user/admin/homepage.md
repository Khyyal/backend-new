# Homepage sections and banners

The homepage is a list of **sections**. Each section has a type, a title, a position, and an optional publishing window.

## Section types

| Type | What clients see |
|---|---|
| **Banner carousel** | A carousel of banners |
| **Curated centers** | Centers you pick, in the order you set |
| **Curated services** | Services you pick, in the order you set. Services show their price, and the discounted price while an offer runs. |
| **Curated promotions** | Running promotions you pick |
| **Curated campaigns** | Running campaigns you pick |
| **Top centers** | Most popular centers, or the nearest first when the client shares their location |

A section's **type cannot be changed** after it is created. Create a new one instead.

## What actually shows

Even if you pick it, an item only shows when it is live:

- centers must be **visible and active**
- services must be **active** and belong to a visible center
- promotions must be running and still have uses left
- campaigns must be running
- the section and each item must be **published** and inside their dates

A section with nothing to show is hidden.

## Banners

Banners belong to **banner carousel** sections only. Each banner has an image, an optional action (open a center, service, promotion, campaign or a link) and an optional publishing window.

## Ordering and picking

Drag sections into order (**Reorder**). For a curated section, open **Items**, search the candidates and choose them.

## Changes show quickly

Edits appear on the next load of the app. Scheduled items appear on time by themselves.

## Results

**Analytics → Home content** shows how often sections and banners are viewed and tapped. It is aggregate only; no individual client is tracked.
