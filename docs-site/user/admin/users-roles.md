# Users and roles

## System users

**Users** lists platform staff. Create a user, assign **roles**, and deactivate or delete them. A deleted user can be **restored**.

- Inactive users cannot sign in and are refused everywhere.
- You can only manage users if you have the matching permission.

## Roles

A role is a named set of permissions, such as "Support" or "Finance". Create roles under **Roles** and tick the permissions each one needs. A user gets the permissions of all their roles.

Built-in roles are protected and cannot be edited or deleted.

## Permissions

Permissions are named `area.action`, for example `centers.view_any`, `promotions.activate`, `fees.manage`, `payouts.manage`, `analytics.view` and `api_docs.view`. Each area of the panel only appears for people who hold its permission.

## Activity log

**Activity log** shows who changed what and when, for audit purposes.
