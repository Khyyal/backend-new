# Analytics and exports

You need the **analytics** permission.

## Dashboards

| Dashboard | Shows |
|---|---|
| **Overview** | The headline numbers |
| **Revenue** | Sales over time |
| **Bookings** | Reservations by status and type |
| **Payments** | Payment outcomes and methods |
| **Clients** | New and returning clients |
| **Centers** | Center activity and growth |
| **Promotions** | Usage and discount cost |
| **Subscriptions** | Plans and renewals |
| **Engagement** | How clients use the app |
| **Home content** | Views and taps on homepage sections and banners |

Figures are built overnight (00:30 UTC), so today's numbers appear the next day. Dates are UTC.

## Exports

Choose **Export** on a list (centers, clients, purchases, a center's purchases or ledger). The file is built in the background; you are **notified when it is ready**, then download it from **Exports**.

- You cannot start the same export again while it is still being built.
- Files are deleted after a while. If a download says it is gone, export again.
