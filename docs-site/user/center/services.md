# Managing services

A **service** is something you sell. There are nine types, and each has its own permission.

| Type | What it is | How clients buy it |
|---|---|---|
| **Recreational riding** | Guided rides | Pick a day and an hour |
| **Visit** | Entry to the center | Pick a day (or a set time) |
| **Event** | A dated event | Buy tickets |
| **Resort** | Overnight stays | Pick a date range, add optional extras |
| **Horse care** | Care offers for a horse | Price options |
| **Horse service** | Other horse services | Price options |
| **Training** | Lessons with a trainer | Pick an hour with a trainer |
| **Membership** | A membership with included visits | Buy a membership |
| **Stabling** | Boarding a horse at the center | Booked by your team for a client's horse; clients see the prices |

## Creating and editing

Open the type from **Services**, then **New**. Names and descriptions are written in **English and Arabic**. New services start **Active**.

- The **type**, **center** and **link (slug)** of a service never change after creation.
- Add **photos**: a cover and gallery images.
- Turn **settings** on or off per service, for example *single-session booking*, *package booking* and *cash on arrival*.

## Prices

Each service has **price options** (for example 30, 60 or 90 minutes, each with a price). Prices are in SAR.

- Editing a price option keeps packages that were already sold. Removing an option removes its package from sale.
- **Packages** let clients pay once for several sessions. Each price option can have one package.
- Set a package to **inactive** to stop selling it without deleting it. Clients no longer see it, and memberships that include it cannot be bought until it is active again. Packages already sold keep working.
- **Stabling** has its own prices: at least one **monthly price** (a number of months, for example 1, 3 or 6, each with a price), an optional **price per day**, and optional **extras** (a name and a price, for example grooming).
- The **lowest price** is shown to clients as the starting price ("from"). For resorts and stabling, extras are not counted.
- While one of your [promotions](./promotions) is running, clients also see the **discounted price**.

## Trainers

Add **trainers** with their own weekly schedule and capacity per hour. A training service is linked to one or more trainers.

## Hiding or removing

Set a service **Inactive** to hide it from clients without losing it. **Deleting** removes it from sale; past bookings and reports keep their history.

Clients only ever see **active** services of a **visible, active** center.
