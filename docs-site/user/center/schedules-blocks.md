# Schedules, periods and blocks

## Schedules

Riding, visit and trainer schedules say **which days and hours** can be booked. Weekdays count from **Sunday**. A window can run until the end of the day (24:00) but a booking cannot cross midnight. Times are UTC.

## Capacity

- Riding and training: a maximum number of **tickets per hour**. Training capacity is per trainer, across all their services.
- Visits: a maximum number of **tickets per day**, shared between entry types.
- Leaving a capacity empty means unlimited.

## Service blocks

A **block** closes a time range so nothing can be booked.

- Attach it to **one service**, or leave the service empty to close the **whole center**.
- Center-wide blocks need the permission to manage all services.
- A booking is refused if it overlaps a block.

## Periods

**Periods** set gender-specific hours where your center offers them.

## Resort closures

For resorts you can close all bookings of a type for a range, for example during maintenance.
