# Offers and coupons

## Offers

**Offers** lists the promotions running now. Open one to see its details and the services it covers, with the discounted starting price.

An offer shows only while it is active, inside its dates and (if it has a weekly schedule) at the right time. It disappears once it has been used up.

## How discounts apply

- Each item can get **one** discount, the biggest one.
- One **order discount** may be added on top.
- Some offers cannot be combined (they are marked exclusive).
- A discount can never make an item cost less than zero.
- Some offers are for a **first booking** only, or have a minimum spend.

You see the final price in the quote before you pay. If the price changed since you looked, the app asks you to confirm again.

## Coupons

Enter a coupon code at checkout. Codes are not case-sensitive.

- If the code is not valid, you see a general "invalid" message.
- If a better automatic offer already applies, the coupon is not used and you are told.
- Coupons may have a limit per person.
