# Running the platform

## Development

```bash
composer dev
```

This runs `php artisan dev`, which starts the local processes the app needs. Under Herd the site is already served at the project's `.test` domain.

## Tests

```bash
composer test
php artisan test --compact modules/Services     # one module
php artisan test --compact --filter="display_price"
```

See [Testing](../conventions/testing).

## Code style

```bash
vendor/bin/pint --dirty --format agent
```

Run Pint before finishing any change that touches PHP.

## Scheduled commands

Each module registers its own schedule in its service provider. In production run `php artisan schedule:run` every minute (cron) and keep a queue worker running.

| Command | Schedule | What it does |
|---|---|---|
| `notifications:dispatch-due-campaigns` | every minute | Sends scheduled notification campaigns that are due |
| `billing:release-unpaid` | every 5 minutes | Releases unpaid subscription holds |
| `analytics:build` | daily 00:30 | Rebuilds the analytics rollups |
| `exports:prune` | daily 03:00 | Deletes expired export files |
| `purchase:generate-payouts` | weekly, Sunday 00:00 | Creates pending payouts from the center ledger (`--cutoff=` to choose the date) |
| `reservations:release-unpaid` | by the Reservations module | Cancels unpaid online holds after `unpaid_hold_minutes` |
| `reservations:send-reminders` | by the Reservations module | Sends booking reminders |
| `reservations:send-expiry-reminders` | by the Reservations module | Warns about expiring packages and memberships |
| `reservations:expire-packages` | by the Reservations module | Expires packages and memberships that passed their end date |
| `promotions:reconcile` | manual | Reports or corrects drift in promotion usage counters (`--dry-run`) |

## API documentation

The endpoint reference is generated by Scribe and served at `/docs` after `php artisan scribe:generate`. These guides are served at `/guide`; see [Keeping these docs current](../conventions/documentation).

Both need a system user with the `api_docs.view` permission.

## This documentation site

```bash
npm run docs:dev      # live preview at http://localhost:5173/guide/
npm run docs:build    # builds into storage/app/docs
```
